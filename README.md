# IT Support Portfolio

A collection of practical IT support work demonstrating troubleshooting knowledge,
documentation skills, and basic scripting/automation.

## Projects

### 1. [Windows Troubleshooting Guide](windows-troubleshooting-guide/README.md)
A knowledge-base–style reference covering common end-user issues: DNS,
printers, VPN, and slow performance. Written in the format used for internal
support documentation, with symptoms, diagnostic steps, and resolutions.

### 2. [Ticket Automation Script](./ticket-automation)
A Python tool that ingests a list of help-desk tickets, automatically
categorizes and prioritizes them by keyword, and generates a triage summary —
the kind of repetitive sorting work that's easy to automate.
